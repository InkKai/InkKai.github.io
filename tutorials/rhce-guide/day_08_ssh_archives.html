遠端連線：SSH 金鑰與安全傳輸

系統管理員的日常就是「遠端工作」。今天我們要學會如何不用打密碼就能安全登入遠端主機，以及如何把檔案打包帶走。

1 SSH 金鑰原理：鎖頭與鑰匙

🔑 鎖匠的比喻

公鑰 (Public Key)：就像一個「鎖頭」。你可以複製幾百個鎖頭，把它們掛在任何你想去的主機上（門上）。鎖頭可以公開給任何人看。
私鑰 (Private Key)：就像這把鎖頭的「鑰匙」。你必須隨身保管好，絕不能給別人。只要你有鑰匙，就能打開所有掛了你鎖頭的門。

2 實作免密碼登入

這是 RHCE Ansible 的基礎，一定要會。

Step 1: 產生鑰匙對

[student@workstation ~]$ ssh-keygen # 一路按 Enter 到底。 # 私鑰存於 ~/.ssh/id_rsa # 公鑰存於 ~/.ssh/id_rsa.pub (要送出去的鎖頭)

Step 2: 派送鎖頭 (Copy ID)

[student@workstation ~]$ ssh-copy-id user@servera # 系統會問你一次密碼。輸入成功後，鎖頭就掛上去了。

Step 3: 登入測試

[student@workstation ~]$ ssh user@servera # 這次應該不需要輸入密碼就能進去了！

3 遠端傳檔：scp (Secure Copy)

用法跟 cp 很像，只是路徑要加主機名稱。

[student@workstation ~]$ scp file.txt user@servera:/tmp # 把本地的 file.txt 傳到 servera 的 /tmp [student@workstation ~]$ scp user@servera:/etc/passwd ./backup # 把 servera 的 /etc/passwd 下載到這裡

4 打包壓縮：tar

Linux 的壓縮檔通常是 .tar.gz。記住這個口訣：xvf (解壓), cvf (壓縮)。

參數 功能
c Create (建立/壓縮)
x Extract (解開)
v Verbose (顯示過程)
f File (指定檔名) - 一定要放在最後面
z Gzip 壓縮 (.tar.gz)
[student@host ~]$ tar -czvf backup.tar.gz /home/student/work # 把 work 資料夾打包壓縮成 backup.tar.gz [student@host ~]$ tar -xvf backup.tar.gz -C /tmp # 把 backup.tar.gz 解壓縮到 /tmp 目錄 (-C Change Directory)

🧪 今日實戰 Lab：備份與傳輸

  1. 建立金鑰：
    在 workstation 產生 SSH 金鑰，並將其複製到 servera (如果你只有一台機器，可以複製給自己 ssh-copy-id localhost)。
  2. 打包資料：
    將 /var/log 目錄打包並壓縮成 logs.tar.gz。
    sudo tar -czvf logs.tar.gz /var/log
  3. 遠端備份：
    使用 scp 將 logs.tar.gz 傳送到遠端主機的 /tmp 目錄。
    scp logs.tar.gz user@localhost:/tmp
