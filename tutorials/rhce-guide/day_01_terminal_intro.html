Linux 的黑盒子：終端機與指令基礎

恭喜你踏出第一步！今天我們要揭開 Linux 最神秘的面紗——黑底白字的「終端機」。別怕，它不是駭客專屬的工具，它只是你跟電腦對話的「麥克風」。

1 核心觀念：Shell 與 Kernel

🍟 麥當勞點餐的比喻

圖形介面 (GUI)： 就像是用「自助點餐機」。螢幕上有什麼圖片，你就只能點什麼。功能受限。

命令列介面 (CLI)： 就像是直接走進「廚房」，跟主廚面對面說話。「我要大麥克去醬加蛋」。只要你會講「廚房術語」（指令），主廚（系統核心）就能為你做任何事。

  • Kernel (核心)：硬體資源的管理者（大腦），只懂 0101。
  • Shell (殼)：你的翻譯官。把你的英文指令 (ls) 翻譯給核心聽。RHEL 預設使用 Bash。

2 指令語法結構

Linux 指令就像英文句子，有固定的文法：

Command + -Options + Arguments

（動詞） + （副詞/修飾） + （受詞）

考試常見錯誤

1. 大小寫敏感：Date 和 date 是不一樣的。
2. 空白鍵：指令與參數之間一定要有空格。錯誤範例：ls-l。

3 導航與路徑概念

這是新手最容易迷路的地方。請牢記這張地圖：

[student@host ~]$ pwd /home/student # Print Working Directory (我在哪？) [student@host ~]$ cd /etc # Change Directory (移動到 /etc)
符號 意義 範例
~ 家目錄 (Home) cd ~ (馬上回家)
.. 上一層 (Parent) cd .. (往回走一步)
. 這裡 (Current) ./script.sh (執行這裡的程式)

4 檔案列表 (ls) 進階

ls 不只是列出檔案，它是你的眼睛。

[student@host ~]$ ls -lha # -l : 長列表 (詳細資訊) # -h : 人類可讀大小 (顯示 KB, MB 而不是 Bytes) # -a : 顯示隱藏檔 (以 . 開頭的檔案) drwxr-xr-x. 2 student student 4.0K Nov 30 10:00 . drwxr-xr-x. 3 root root 20 Nov 30 09:00 .. -rw-------. 1 student student 500 Nov 30 10:00 .bash_history

5 獲取幫助 (Man Page)

考試時沒有 Google，只有 Man Page。這是你的救命稻草。

[student@host ~]$ man passwd # 進入手冊模式...
Space：往下翻一頁
b：往上翻一頁 (Back)
/關鍵字：搜尋 (例如 /-l)
q：離開 (Quit)

今日實戰 Lab

請開啟終端機，完成以下任務：

  1. 使用 whoami 確認身份，pwd 確認位置。
  2. 進入 /usr/share/doc 目錄。
  3. 列出該目錄下所有以 z 開頭的檔案 (提示: ls z*)。
  4. 使用 cd 快速回到家目錄。
  5. 查閱 date 的 man page，找出如何顯示 UTC 時間的參數 (date -u)。
