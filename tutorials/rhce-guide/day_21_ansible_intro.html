Ansible 初探：環境建置與架構

恭喜進入 RHCE 自動化階段！現在我們不只要會做菜，還要學會「指揮機器人做菜」。Ansible 是目前最紅的自動化工具，因為它簡單、免代理程式 (Agentless)。

1 什麼是 Ansible？

🎮 萬能遙控器的比喻

以前你要設定 100 台伺服器，得像跑到每一台電視機前去轉台（SSH 進去打指令）。
Ansible 就像一把「萬能遙控器」。你只要在控制主機 (Control Node) 按下按鈕，紅外線 (SSH) 就會發射出去，100 台受控主機 (Managed Nodes) 就會同時轉台。

Ansible 的三大優點：

  • Agentless：不用在受控端裝軟體，只要有 SSH 和 Python 就行。
  • Idempotent (冪等性)：這是最重要的觀念！不管執行幾次，結果都一樣。如果已經裝好了，它就不會再裝一次（不會報錯）。
  • YAML：使用人類看得懂的語言寫劇本。

2 安裝 Ansible

在 RHEL 9 中，Ansible 包含在 ansible-core 套件中。

[student@control ~]$ sudo dnf install ansible-core -y # 安裝核心套件。 [student@control ~]$ ansible --version # 檢查版本。

3 點名簿：Inventory

你要控制誰？這些主機名單寫在 Inventory 檔案裡。常用 INI 格式。

# inventory 檔案範例
[webservers]
servera.lab.example.com
serverb.lab.example.com

[dbservers]
serverc.lab.example.com

[all:vars]
ansible_user=devops

群組 (如 [webservers]) 讓你一次控制一類機器。

4 設定檔：ansible.cfg

Ansible 怎麼知道 Inventory 在哪？怎麼知道要用哪個帳號登入？

🔥 優先權陷阱 (必考)

  1. ANSIBLE_CONFIG 環境變數 (最高)
  2. ./ansible.cfg (目前目錄，最常用)
  3. ~/.ansible.cfg (家目錄)
  4. /etc/ansible/ansible.cfg (全域預設，最低)
[student@control ~]$ vim ansible.cfg [defaults] inventory = ./inventory remote_user = devops ask_pass = false # 設定預設 Inventory 位置和登入帳號。 [privilege_escalation] become = true become_method = sudo become_user = root become_ask_pass = false # 設定自動提權 (sudo)。

5 臨時指令 (Ad-Hoc Commands)

不用寫劇本，直接下指令。適合測試或簡單任務。

語法：ansible [主機/群組] -m [模組] -a "[參數]"

[student@control ~]$ ansible all -m ping # 測試所有主機連線 (ping 模組)。 [student@control ~]$ ansible webservers -m command -a "id" # 在 webservers 群組執行 "id" 指令。

🧪 今日實戰 Lab：打造控制中心

  1. 準備環境：
    建立目錄 ~/ansible-lab 並進入。
  2. 建立 Inventory：
    建立 inventory 檔案，內容包含：
    [web]
    servera
    localhost
  3. 建立設定檔：
    建立 ansible.cfg，指向剛剛的 inventory，並關閉 host_key_checking (方便測試)。
    [defaults]
    inventory = ./inventory
    host_key_checking = false
  4. 測試連線：
    使用 Ad-Hoc 指令測試。
    ansible all -m ping
