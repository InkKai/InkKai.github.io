軟體管家與時光機：YUM/DNF 與打包

恭喜完成 Phase 1！今天是基礎篇的最後一課。我們要學習如何像使用 App Store 一樣安裝軟體，並且學會如果安裝錯了，如何用「時光機」復原。

1 軟體安裝：RPM 與 DNF

📦 網購與超商的比喻

  • RPM (Red Hat Package Manager)：就像是「單獨下載的 APK 檔」。你必須自己解決所有問題（例如：安裝 A 需要先裝 B，RPM 不會幫你下載 B）。
  • DNF (Dandified YUM)：就像「App Store」。它會幫你自動計算依賴關係。你只要說「我要裝 A」，它會自動幫你下載 A 和 B，並裝好。

註：yum 是舊版指令，現在 RHEL 8/9 中，yum 其實就是 dnf 的連結。兩個通用，但建議用 dnf。

2 軟體操作：dnf

這是你最常用的指令。

[root@host ~]# dnf search "web server" # 搜尋軟體。不知道軟體確切名稱時用。 [root@host ~]# dnf install httpd # 安裝軟體。 [root@host ~]# dnf remove httpd # 移除軟體。 [root@host ~]# dnf list installed # 列出已經安裝的軟體。

3 軟體倉庫：Repository (Repo)

DNF 去哪裡下載軟體？答案是 Repo。 設定檔通常放在 /etc/yum.repos.d/ 目錄下，副檔名必須是 .repo。

# 範例 Repo 檔案內容

[BaseOS]
name=Red Hat Enterprise Linux 9 - BaseOS
baseurl=https://cdn.redhat.com/...
enabled=1
gpgcheck=1

4 系統更新與時光機

更新系統

[root@host ~]# dnf update # 更新所有軟體到最新版。

DNF History (後悔藥)

不小心裝錯軟體，或是更新後系統壞了怎麼辦？

[root@host ~]# dnf history # 查看操作歷史紀錄 (會顯示 ID, 時間, 做了什麼)。 [root@host ~]# dnf history undo 5 # 復原 ID 為 5 的那次操作。太神啦！

🧪 今日實戰 Lab：軟體安裝與復原

  1. 搜尋軟體：
    搜尋一個叫做 tmux 的終端機多工軟體。
    dnf search tmux
  2. 安裝軟體：
    安裝它。
    sudo dnf install tmux -y
  3. 檢查歷史：
    查看 DNF 的操作紀錄，找出剛剛安裝的那筆 ID。
    dnf history
  4. 時光倒流：
    使用 undo 指令移除剛剛安裝的 tmux (模擬安裝錯了要復原)。
    sudo dnf history undo [ID]
