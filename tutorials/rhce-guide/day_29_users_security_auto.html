系統自動化 II：使用者與安全自動化

這是考前的最後一塊拼圖。我們要用 Ansible 批量建立使用者、設定密碼、派送 SSH 公鑰，並且搞定防火牆和 SELinux 設定。這在管理幾百台機器時是救命技能。

1 建立使用者：User 模組

密碼不能用明文，要用 Hash。我們可以用 `password_hash` 過濾器。

- name: Create user tony ansible.builtin.user: name: tony groups: wheel # 附加群組 state: present password: "{{ 'mypassword' | password_hash('sha512') }}" # 注意：實務上密碼應該放在 Vault 裡，這裡為了演示直接寫出來。

2 派送 SSH 公鑰

不用再一台一台跑 ssh-copy-id 了。

- name: Set authorized key for tony ansible.posix.authorized_key: user: tony state: present key: "{{ lookup('file', '/home/student/.ssh/id_rsa.pub') }}" # lookup('file', ...) 會讀取控制端 (Control Node) 的檔案內容。

3 防火牆自動化：Firewalld

開啟 Port 或 Service，記得要 permanent: yes 和 immediate: yes。

- name: Open HTTP port ansible.posix.firewalld: service: http permanent: yes # 寫入設定檔 (重開機有效) immediate: yes # 現在立刻生效 (不用 reload) state: enabled

4 SELinux 自動化

還記得 semanage fcontext 和 restorecon 嗎？Ansible 也有模組。

- name: Set context for /web community.general.sefcontext: target: '/web(/.*)?' setype: httpd_sys_content_t state: present # 這一步等於 semanage fcontext -a ... - name: Apply context ansible.builtin.command: restorecon -Rv /web # 目前還沒有很好的原生模組做 restorecon，通常直接 call command。 # 或者可以用 community.general.secontext 模組 (如果有的話)。
