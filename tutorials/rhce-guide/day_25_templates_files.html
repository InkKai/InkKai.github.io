檔案派送：Template 模板引擎

自動化的精髓在於「客製化」。如果 100 台主機的設定檔都長一模一樣，那用 copy 就好。但如果每台主機的 IP、名稱都不一樣呢？這時候就需要 Jinja2 Template。

1 Copy 與 Template 的差別

📠 影印機 vs 填空獎狀

copy 模組：就像影印機。來源檔案是什麼，印出來就是什麼，完全靜態。
template 模組：就像套印獎狀。檔案裡留有空格 ({{ name }})，印表機 (Ansible) 在列印時，會自動幫你填上該主機的名字、IP 或其他變數。

2 Jinja2 語法 (Python 模板語言)

Jinja2 檔案的副檔名通常是 .j2。

1. 變數置換 (最常用)

Welcome to {{ ansible_hostname }}.
My IP is {{ ansible_default_ipv4.address }}.

2. 迴圈 (For Loop)

{% for user in users %}
User: {{ user }}
{% endfor %}

3. 條件 (If)

{% if PORT is defined %}
Listen {{ PORT }}
{% else %}
Listen 80
{% endif %}

3 使用 Template 模組

- name: Deploy config file ansible.builtin.template: src: httpd.conf.j2 # 本地的模板檔 (.j2) dest: /etc/httpd/conf/httpd.conf # 遠端的目的檔 (沒有 .j2) owner: root group: root mode: '0644' notify: Restart Httpd # 通常設定檔改了就要重啟

🧪 今日實戰 Lab：動態歡迎頁面

  1. 建立模板 (index.html.j2)：
    內容包含：
    Hello, I am {{ ansible_hostname }}.
    My OS is {{ ansible_distribution }} {{ ansible_distribution_version }}.
  2. 撰寫 Playbook：
    使用 template 模組，將 index.html.j2 部署到所有 web servers 的 /var/www/html/index.html。
  3. 執行與驗證：
    執行劇本。
    使用 curl 訪問不同的主機，你會發現它們回傳的網頁內容雖然來自同一個模板，但顯示的 Hostname 和版本號都是**各自**的。這就是自動化的威力！
