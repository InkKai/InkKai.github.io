精準搜尋：正規表示式與 Grep

歡迎來到 Phase 2！今天我們要學習如何在大海（成千上萬行的 Log）中撈針（關鍵錯誤訊息）。學會正規表示式 (Regex)，你就能像魔術師一樣操控文字。

1 搜尋神器：Grep

🔍 篩子的比喻

Grep 就像一個濾網。你把一桶沙子（檔案內容）倒過去，它只會留下你想要的黃金（關鍵字行），其他的沙子通通丟掉。

[student@host ~]$ grep "root" /etc/passwd # 在 /etc/passwd 檔案中，搜尋包含 "root" 的每一行。 [student@host ~]$ grep -i "error" /var/log/messages # -i (Ignore case)：不分大小寫 (Error, error, ERROR 都抓)。 [student@host ~]$ grep -v "student" /etc/passwd # -v (Invert)：反向搜尋。顯示「不包含」student 的行。

2 正規表示式 (Regex)：文字魔法

Regex 是一種用符號來描述「文字特徵」的語言。考試必考！

符號 意義 範例
^ 行首 (Start of line) ^root (只找開頭是 root 的行)
$ 行尾 (End of line) bash$ (只找結尾是 bash 的行)
. 任意一個字元 r..t (找 root, r00t, rest...)
* 重複前一個字元 0 次或多次 go*d (找 gd, god, good, goood...)
[ ] 括號內的任一字元 [rR]oot (找 root 或 Root)

💡 實戰範例：找空行

空行的特徵是什麼？就是「開頭緊接著結尾」。
所以 grep "^$" file.txt 可以找出所有空行。
而 grep -v "^$" file.txt 可以刪除所有空行！(考試常用技巧)

3 Vim 中的搜尋取代

在 Vim 裡面也可以用 Regex。

  • /keyword：往下搜尋 keyword。
  • ?keyword：往上搜尋 keyword。
  • :%s/old/new/g：全文搜尋取代。把所有的 old 換成 new。

4 自動化的起點：Shell Script

Shell Script 就是把一堆指令寫在一個檔案裡，讓電腦一次執行。

[student@host ~]$ vim my_script.sh # 內容如下： #!/bin/bash # 第一行一定要是這個！稱為 Shebang，告訴系統用 bash 來執行。 echo "Hello, checking system..." date grep "^root" /etc/passwd
[student@host ~]$ chmod +x my_script.sh # 給予執行權限 (x) [student@host ~]$ ./my_script.sh # 執行它！
