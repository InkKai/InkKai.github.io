硬碟蛋糕切法 II：LVM 彈性磁碟管理

傳統分區 (Partitions) 就像把房間隔間牆砌死，想改大小就要打掉重練。LVM (Logical Volume Manager) 就像用活動隔板，隨時可以把空間變大變小。

1 LVM 三層架構

🧱 樂高積木比喻

  1. PV (Physical Volume)：樂高積木塊。這是最底層的硬碟或分區 (e.g., /dev/vdb1)。
  2. VG (Volume Group)：積木桶。把很多 PV 丟進去，變成一個大儲存池。
  3. LV (Logical Volume)：組好的模型。從桶子裡拿積木組出來的虛擬硬碟，這才是我們最後格式化和使用的東西。

2 建立 LVM 的步驟

口訣：P -> V -> L (Physical -> Volume -> Logical)。

[root@host ~]# pvcreate /dev/vdb1 /dev/vdc1 # 1. 初始化 PV (把硬碟貼上 LVM 標籤)。 [root@host ~]# vgcreate myvg /dev/vdb1 /dev/vdc1 # 2. 建立 VG (桶子)，名字叫 myvg，把這兩個 PV 丟進去。 [root@host ~]# lvcreate -n mylv -L 500M myvg # 3. 建立 LV (模型)，名字叫 mylv，大小 500MB，從 myvg 拿空間。 # -n: name, -L: size

最後，別忘了格式化和掛載：

[root@host ~]# mkfs.xfs /dev/myvg/mylv [root@host ~]# mount /dev/myvg/mylv /data

3 空間不夠了？線上擴充！

這是 LVM 最強大的功能。你可以在不關機、不卸載的情況下，把硬碟變大。
步驟：先擴充 LV (拿積木)，再擴充檔案系統 (抹平奶油)。

[root@host ~]# lvextend -L +200M /dev/myvg/mylv # 擴充 LV。+200M 代表「增加」200M。(如果是 200M 代表「變成」200M) # 或者：lvextend -l +100%FREE /dev/myvg/mylv (把剩下空間全吃光) [root@host ~]# xfs_growfs /data # 擴充 XFS 檔案系統 (注意：參數是「掛載點」，不是裝置名稱！)。 # 如果是 ext4，請用 resize2fs /dev/myvg/mylv

4 縮減容量 (危險區)

⚠️ 警告

1. XFS 不支援縮減！ 你只能擴充，不能縮小。如果一定要縮小，只能備份資料、刪除 LV、重建、還原資料。
2. ext4 可以縮減，但風險很高，必須先卸載 (umount)。

🧪 今日實戰 Lab：空間魔術師

假設你有一個分區 /dev/vdb2 (500MB)。

  1. 建立 LVM：
    建立 PV, VG (名為 datavg), LV (名為 datalv, 大小 200MB)。
    格式化為 xfs 並掛載到 /mnt/data。
  2. 擴充容量：
    老闆說 200MB 不夠，要加到 400MB。
    使用 lvextend 和 xfs_growfs 完成擴充。
  3. 驗證：
    使用 df -h 確認 /mnt/data 的容量是否真的變大了。
