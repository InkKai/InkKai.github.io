權限進階：ACL 存取控制列表

基本的 rwx 權限只有三種人：擁有者、群組、其他人。但如果你想讓「除了 Tony 以外的所有人」都能讀取，或者只給「財務部經理」特別權限怎麼辦？你需要 ACL (Access Control Lists)。

1 什麼是 ACL？

📜 VIP 邀請卡

標準權限 (chmod)：像是大門規定。「員工可以進來，路人不行」。
ACL (setfacl)：像是 VIP 名單。「雖然路人不行進來，但這張名單上的 John 和 Mary 可以例外進來」。

當你看到 ls -l 的權限後面多了一個 + 號 (例如 -rw-rwxr--+)，就代表這個檔案有 ACL 設定。

2 查看權限：getfacl

[student@host ~]$ getfacl file.txt # file: file.txt # owner: student # group: student user::rw- user:tony:rw- <-- 這是 ACL 新增的，給 tony 讀寫權限 group::r-- mask::rw- other::r--

3 設定權限：setfacl

語法：setfacl -m u:[使用者]:[權限] [檔案]

動作 指令
新增/修改使用者權限 setfacl -m u:tony:rw file.txt
新增/修改群組權限 setfacl -m g:managers:rx dir/
移除特定使用者權限 setfacl -x u:tony file.txt
移除所有 ACL (歸零) setfacl -b file.txt

4 繼承權限：Default ACL

如果我希望在 project 目錄下新增的檔案，自動都讓 tony 可以讀寫，該怎麼辦？
我們需要設定 Default ACL (只對目錄有效)。

[root@host ~]# setfacl -m d:u:tony:rw /project # 注意前面的 d:，代表 default。 # 以後在 /project 裡建立的新檔案，tony 自動會有 rw 權限。

🧪 今日實戰 Lab：專案權限控管

  1. 建立環境：
    建立目錄 /data/project，並將其群組改為 wheel，權限設為 770 (其他人不能進)。
    mkdir -p /data/project; chown :wheel /data/project; chmod 770 /data/project
  2. 設定例外 (ACL)：
    假設有一個實習生使用者 student (他不屬於 wheel 群組)。請使用 ACL 讓他對該目錄有 r-x 權限。
    setfacl -m u:student:rx /data/project
  3. 設定預設繼承：
    確保未來在該目錄下建立的任何檔案，student 都能自動擁有讀取權限。
    setfacl -m d:u:student:r /data/project
  4. 驗證：
    在目錄裡 touch test.txt，然後用 getfacl test.txt 檢查 student 是否自動獲得了權限。
