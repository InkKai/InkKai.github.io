網路設定：IP、DNS 與除錯

沒有網路的伺服器就像一座孤島。今天我們要學習如何幫電腦申請「門牌號碼」(IP)，並設定「電話簿」(DNS)，讓它能與世界連結。

1 網路三要素：IP, Gateway, DNS

📮 郵局投遞的比喻

  • IP Address (IP 位址)：你家的門牌號碼。例如 192.168.1.100。網路上每個裝置都要有唯一的號碼。
  • Gateway (通訊閘)：你住的社區的大門警衛室。你要去外面（Internet），一定要先經過這裡。
  • DNS (網域名稱系統)：電話簿。你記不住 142.250.183.206，但你記得住 google.com。DNS 負責幫你把名字翻譯成號碼。

2 檢查狀態：ip 與 ping

以前我們用 ifconfig，但現在它已經過時了。現在請用 ip 指令。

[student@host ~]$ ip addr show # 顯示所有網卡的 IP 位址。 # 找 "inet" 後面的數字，那就是你的 IPv4 位址。 [student@host ~]$ ping -c 4 8.8.8.8 # 測試網路通不通。-c 4 代表只 ping 4 次就停 (不然它會一直跑)。

3 設定神器：nmcli

NetworkManager Command Line Interface。
這是 RHCSA 考試一定要會的指令。它會自動幫你修改設定檔，不用怕打錯字。

觀念區分：Device vs Connection

  • Device (裝置)：實體的網卡，例如 eth0, ens160。
  • Connection (連線設定)：設定檔，例如「在家連線」、「公司連線」。你可以隨時切換不同的設定檔套用到同一個網卡上。

1. 查看連線

[student@host ~]$ nmcli con show # 顯示所有連線設定檔 (con = connection)

2. 新增連線 (設定靜態 IP)

[root@host ~]# nmcli con add con-name "static-eth0" ifname eth0 type ethernet ipv4.method manual ipv4.addresses 192.168.1.100/24 ipv4.gateway 192.168.1.1 # 這行指令很長，考試要背！ # con-name: 設定檔名稱 (自訂) # ifname: 網卡名稱 (要看系統顯示什麼) # type: 網路類型 (ethernet) # ipv4.method manual: 手動設定 IP (靜態)

4 修改設定：DNS 與生效

設定完 IP 後，通常還要加 DNS。我們用 mod (modify) 來修改現有的設定檔。

[root@host ~]# nmcli con mod "static-eth0" ipv4.dns "8.8.8.8 1.1.1.1" # 加入 Google 和 Cloudflare 的 DNS [root@host ~]# nmcli con up "static-eth0" # 重要！修改完一定要 "up" (啟用) 才會生效。這會重新讀取設定檔。

🧪 今日實戰 Lab：建立辦公室網路

假設你的網卡名稱是 eth0 (如果你的虛擬機是 ens160 或其他名字，請自行替換)。

  1. 建立設定檔：
    建立一個名為 office-net 的連線，設定 IP 為 172.25.250.10/24，Gateway 為 172.25.250.254。
    nmcli con add con-name office-net ifname eth0 type ethernet ipv4.method manual ipv4.addr 172.25.250.10/24 ipv4.gateway 172.25.250.254
  2. 加入 DNS：
    設定 DNS 為 172.25.250.254。
    nmcli con mod office-net ipv4.dns 172.25.250.254
  3. 啟用連線：
    讓設定生效。
    nmcli con up office-net
  4. 驗證：
    檢查 IP 是否正確，並嘗試 ping Gateway。
    ip addr show eth0
    ping -c 2 172.25.250.254
