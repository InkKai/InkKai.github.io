檔案總管再見：檔案管理與目錄結構

今天我們要拋棄滑鼠。用指令來蓋房子（建目錄）、搬家（移動）和影印（複製）。更重要的是，我們要學會 Linux 的「住址系統」—— FHS。

1 Linux 的地圖：FHS 架構

Linux 的目錄不是亂放的。/etc (設定), /var (變動資料), /home (家)。

2 蓋房子：mkdir

$ mkdir -p a/b/c

3 影印機：cp

記得加 -p 保留權限！

4 搬運工：mv

$ mv file.txt /tmp

5 碎紙機：rm

rm -rf 很危險，請小心。

6 連結：Links

ln -s (軟連結), ln (硬連結)。

  2. cp -p 備份檔案
