系統自動化 I：儲存與網路自動化

今天我們要挑戰用 Ansible 來「遙控」我們在 Day 16-17 學過的硬碟管理，以及 Day 9 學過的網路設定。記住，目標是「從零到有」，無論硬碟現在是什麼狀態，跑完 Playbook 就會變成我們要的樣子。

1 儲存自動化：LVM 三部曲

我們需要使用三個模組來完成 PV -> VG -> LV 的建立。

- name: Create Partition (切分區) community.general.parted: device: /dev/vdb number: 1 state: present flags: [ lvm ] - name: Create Volume Group (建立 VG) community.general.lvg: vg: myvg pvs: /dev/vdb1 - name: Create Logical Volume (建立 LV) community.general.lvol: vg: myvg lv: mylv size: 1000M

2 格式化與掛載

filesystem 模組負責 mkfs。
mount 模組負責 mount 並且會自動寫入 /etc/fstab (這點比手動強太多了！)。

- name: Format as XFS community.general.filesystem: fstype: xfs dev: /dev/myvg/mylv - name: Mount and enable boot persistence ansible.posix.mount: path: /data src: /dev/myvg/mylv fstype: xfs state: mounted # state: mounted 代表「現在掛載」+「寫入 fstab」。

3 網路自動化：使用 System Role

🔥 考試必殺技

雖然有 nmcli 模組，但 Red Hat 官方推薦使用 rhel-system-roles.network 這個 Role。 你只需要定義變數，不用寫 Task！

--- - name: Configure Network hosts: all roles: - rhel-system-roles.network # 呼叫官方 Role vars: network_connections: # 定義這個神奇變數 - name: static-eth0 interface_name: eth0 type: ethernet ip: address: - 192.168.1.100/24 gateway: 192.168.1.1
