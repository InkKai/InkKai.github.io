服務管理員：Systemd 與守護進程

為什麼網頁伺服器一開機就會跑？為什麼拔掉 USB 隨身碟系統知道？這都是 Systemd 這個超級總管的功勞。

1 什麼是 Systemd？

🏢 大樓管理員的比喻

Kernel 是大樓的建築結構，而 Systemd (PID 1) 就是大樓的「總幹事」。
它是一開機第一個起床的人 (PID=1)，然後負責喚醒其他所有員工 (Services)。
那些在背景默默工作的員工（如網頁伺服器、列印服務），我們稱為 Daemon (守護進程)，通常名稱字尾都有個 'd' (例如 httpd, sshd)。

2 遙控器：systemctl

我們使用 systemctl 指令來命令總幹事做事。

指令 動作 比喻
systemctl start httpd 啟動服務 叫員工現在開始上班。
systemctl stop httpd 停止服務 叫員工下班回家。
systemctl restart httpd 重啟服務 叫員工先下班，立刻再重新上班 (用於套用新設定)。
systemctl reload httpd 重新載入 叫員工不用下班，直接看新的工作手冊 (不中斷連線)。

3 檢查狀態：status

想知道服務有沒有在偷懶？

[student@host ~]$ systemctl status sshd
  • active (running)：正常運作中。
  • inactive (dead)：沒在跑，休息中。
  • failed：啟動失敗！(趕快去看 log 查原因)。

4 開機設定：enable / disable

「現在啟動」跟「開機自動啟動」是兩回事！這是新手最常搞混的。

systemctl enable httpd

設定為「開機自動啟動」。
它會在 /etc/systemd/system/ 建立一個連結。
注意：這指令不會讓服務「現在」立刻跑起來。

systemctl disable httpd

取消開機自動啟動。
下次重開機，它就不會自己跑起來了。

💡 懶人技巧

如果你想「設定開機啟動」同時「現在立刻啟動」，可以用：
systemctl enable --now httpd

🧪 今日實戰 Lab：網頁伺服器管理

  1. 安裝服務 (預先準備)：
    先裝好 Apache 網頁伺服器 (httpd)。
    sudo dnf install httpd -y
  2. 啟動並設為開機自啟：
    使用一行指令完成這兩件事。
    sudo systemctl enable --now httpd
  3. 確認狀態：
    檢查它是否真的在跑，且是 enabled 狀態。
    systemctl status httpd
  4. 禁止服務：
    讓它下次開機不會自動跑，但現在不要關掉它。
    sudo systemctl disable httpd
