我是誰？使用者、群組與身份切換

Linux 是一個「多使用者」系統，這意味著同一時間可以有很多人連進來。今天我們要學習如何當「人事部經理」：發識別證（建立帳號）、分部門（群組），以及給予特殊權力（sudo）。

1 核心觀念：識別證與部門

🏢 公司的比喻

在 Linux 公司裡，有三種角色：

  • Root (超級管理員)：老闆。他有萬能鑰匙，想拆大樓都可以。UID = 0。
  • User (一般使用者)：員工。只能在自己的辦公桌 (Home Directory) 活動。UID > 1000。
  • Group (群組)：部門。例如「行銷部」的人可以共用某些檔案，但「會計部」的人看不到。

系統怎麼認得你？不是靠名字，是靠 UID (User ID) 和 GID (Group ID)。這就像你的員工編號。

2 管理員工：useradd / userdel

這些指令通常只有 Root 能執行（廢話，你見過員工自己發識別證的嗎？）。

[root@localhost ~]# useradd tony # 建立一個叫 tony 的使用者。系統會自動： # 1. 在 /etc/passwd 新增一行 # 2. 建立 /home/tony 家目錄 # 3. 建立一個同名的 tony 群組 [root@localhost ~]# userdel -r tony # 刪除 tony。注意！一定要加 -r，才會連他的家目錄 (/home/tony) 一起刪掉。

重要檔案 (背起來！)

  • /etc/passwd：使用者清單 (包含 UID, GID, 家目錄位置)。
  • /etc/shadow：密碼檔 (加密過的，只有 Root 能看)。

3 管理部門：groupadd / usermod

一個人可以屬於多個部門（群組）。一個是主要群組 (Primary Group)，其他是附加群組 (Secondary Group)。

[root@localhost ~]# groupadd marketing # 建立一個叫 marketing 的群組。 [root@localhost ~]# usermod -aG marketing tony # 將 tony 加入 marketing 群組。 # -a (Append): 附加，不覆蓋原本的群組。 # -G (Group): 指定附加群組。

4 變身術：su 與 sudo

su (Switch User)

完全切換身分。
su - ：切換成 Root，並載入 Root 的環境變數（推薦）。
需要輸入目標使用者的密碼（例如 Root 的密碼）。

sudo (SuperUser Do)

借用權力。
sudo command：用管理員權限執行這一行指令。
需要輸入自己的密碼。

5 密碼管理：passwd

只有 Root 可以改別人的密碼，一般人只能改自己的。

[root@localhost ~]# passwd tony # 強制修改 tony 的密碼 (不需要知道舊密碼)。 [student@localhost ~]$ passwd # 修改自己的密碼 (需要輸入舊密碼)。

🧪 今日實戰 Lab：人事部的一天

  1. 建立部門：
    切換成 Root (sudo -i)，建立兩個群組：devops 和 design。
  2. 招募員工：
    建立使用者 alex，並指定他的附加群組為 devops。
    useradd -G devops alex
  3. 設定密碼：
    幫 alex 設定密碼為 password123。
    echo "password123" | passwd --stdin alex
  4. 驗收成果：
    檢查 id alex，確認他的 UID, GID 和群組是否正確。
    id alex
