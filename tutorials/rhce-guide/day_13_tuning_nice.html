效能調校：Tuned 與優先權管理

你的伺服器是要跑高效能運算，還是要省電當檔案伺服器？今天我們學習如何切換系統的「駕駛模式」，以及如何讓重要的程式插隊先跑。

1 系統駕駛模式：Tuned

🚗 跑車模式 vs 省油模式

Tuned 是一個守護進程，它會根據你選擇的 Profile (設定檔) 自動調整 CPU 頻率、磁碟 IO 設定等幾百項參數。
就像汽車切換 Sport 模式（高效能）或 Eco 模式（省電）。

[student@host ~]$ tuned-adm list # 列出所有可用的 Profile。 # 常見的有：virtual-guest (虛擬機用), throughput-performance (高效能), balanced (平衡)。 [student@host ~]$ tuned-adm active # 查看目前正在用哪一個 Profile。 [root@host ~]# tuned-adm profile throughput-performance # 切換到高效能模式 (需要 root)。

2 禮讓運動：Nice 值

Linux 的每個 Process 都有一個 Nice 值，範圍是 -20 到 19。
Nice 值越高，代表這個人越「好說話 (Nice)」，越願意禮讓別人，所以優先權越低。
Nice 值越低 (-20)，代表這個人越「壞 (Not Nice)」，越要搶第一，優先權越高。

-20 (最兇，最高優先) <--- 0 (預設) ---> 19 (最Nice，最低優先)
[student@host ~]$ nice -n 5 sleep 1000 & # 啟動一個 Nice 值為 5 的程式 (比一般程式更禮讓)。

3 調整優先權：renice

如果程式已經在跑了，我們可以用 renice 來改變它的優先權。

⚠️ 權限限制

一般使用者只能把 Nice 值調高 (變更禮讓)。只有 Root 可以把 Nice 值調低 (變更兇)。

[root@host ~]# renice -n -10 -p 1234 # 把 PID 1234 的優先權調到 -10 (非常高優先)。

🧪 今日實戰 Lab：效能大師

  1. 檢查並切換 Profile：
    檢查目前 tuned profile。如果不是 virtual-guest，請切換過去 (假設你在虛擬機)。如果是實體機，切換到 balanced。
    tuned-adm active
    sudo tuned-adm profile virtual-guest
  2. 啟動背景程式：
    啟動一個 sha1sum /dev/zero & 指令 (這會吃大量 CPU)。記下它的 PID。
  3. 觀察並調整：
    使用 top 觀察它的 CPU 使用率和 NI (Nice) 值。
    使用 renice 將其 Nice 值改為 19 (最低優先)。
    sudo renice -n 19 -p [PID]
  4. 善後：
    別忘了把那個吃 CPU 的怪獸殺掉。
    kill [PID]
