為什麼要發起這個挑戰？

市面上的 Red Hat 認證課程動輒數萬元。我們相信教育應該是平等的。

本計畫將官方教材 (RH124/134/294) 的 39 個單元濃縮成「電腦小白」也能看懂的實戰筆記。 不用花錢補習，也能掌握企業級的 Linux 技能。

學習成效保證

  • RHCSA (EX200)：系統管理、儲存、安全、容器
  • RHCE (EX294)：Ansible 自動化運維
  • 完全免費：所有的 Lab 與筆記皆開源

  • CPU 處理器： 建議 12 核心 虛擬化 VT-x
  • 分配：圖形化 RHEL (4核) + 無圖形化 RHEL (2核) + 預留
  • RAM 記憶體： 建議 12 GB
  • 分配：足夠同時運行兩台虛擬機 (GUI + Server)
  • 硬碟空間： 建議 100 GB
  • 分配：Server A + Server B + 快照空間
