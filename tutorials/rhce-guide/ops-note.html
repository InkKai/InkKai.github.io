Phase 1: HTML 架構 (Structure)
HTML 的本質是什麼？
HTML 就像是 Switch 的 Running Config。瀏覽器讀取它來決定畫面的結構。
Live Server 的原理？
在 Local (127.0.0.1) 的 Ephemeral Port (如 5500) 起一個 Web Service，並用 WebSocket 監聽檔案變更。
<head> 標籤的作用？
類似 Packet Header。存放 Metadata（編碼、標題、CSS 連結），使用者看不到，但對解析至關重要。
什麼是語意化標籤 (Semantic Tags)？
如 <nav>, <main>。就像 Linux 的標準目錄結構 (/bin, /etc)，讓機器知道區塊的用途，而不是全部丟在 /tmp (<div>)。
相對路徑 ./ 和 ../ 的意思？
與 Linux 檔案系統完全一致。./ 是當前目錄，../ 是上一層目錄。
顯示程式碼要用什麼標籤？
使用 <pre> (保留格式) 包住 <code> (標示代碼)。
Viewport Meta Tag 的作用？
width=device-width。告訴瀏覽器把視窗寬度設為硬體寬度，是 RWD 手機版排版的基礎。
HTML 註解怎麼寫？
<!-- 註解內容 -->，瀏覽器會忽略它，就像 Shell Script 的 #。
引入 CSS 的語法？
在 Head 裡使用 <link rel="stylesheet" href="style.css">。
引入 JS 的語法？
通常在 Body 結束前使用 <script src="script.js"></script>。
Phase 2: CSS 排版 (Styling)
CSS Grid 的用途？
精準的版面切割，類似硬碟分割 (Partitioning)。
CSS Flexbox 的用途？
一維的彈性排列，類似 LVM，內容多了自動撐開，少了自動縮小。
Position: Sticky 是什麼？
將元素「釘」在視窗上，類似將視窗設為 "Always on Top"，捲動時會跟著跑。
RWD Media Query 寫法？
@media (max-width: 768px) { ... }。類似 Shell 的 if [ width -lt 768 ]; then ...。
如何設定等寬字體？
font-family: 'Consolas', monospace;。這對顯示程式碼對齊很重要。
Hover 效果是什麼？
a:hover。當滑鼠游標懸停時觸發的樣式改變 (Event Trigger)。
Box Model (盒模型) 包含哪些？
Content(內容) -> Padding(內距) -> Border(邊框) -> Margin(外距)。
如何隱藏一個元素？
display: none;。元素會完全從 Render Tree 消失，不佔空間。
Zebra Striping (表格條紋) 怎麼做？
tr:nth-child(even)。選取偶數列變色，像 awk 'NR%2==0'。
vh 和 vw 單位是什麼？
Viewport Height/Width。100vh 等於螢幕可視範圍的 100% 高度。
Phase 3: JS 邏輯 (Scripting)
Let vs Const 差別？
const 是唯讀變數 (Immutable)，let 是一般變數。系統工程師應優先用 const 避免改錯參數。
DOM 是什麼？
Document Object Model。瀏覽器把 HTML 解析成的樹狀結構，JS 透過操作 DOM 來改變畫面。
addEventListener 是做什麼的？
事件監聽器。類似 Daemon 監聽 Signal (如 Click, Scroll, Keydown)。
LocalStorage 是什麼？
瀏覽器端的簡易資料庫。資料會寫入硬碟，重開機(重整網頁)後資料還在。
如何實現「一鍵複製」？
使用 navigator.clipboard.writeText() API。
Subnet Mask 計算公式？
可用 IP = 2^(32 - CIDR) - 2。JS 用 Math.pow(2, n) 計算。
如何用 JS 切換 CSS Class？
element.classList.toggle('classname')。
搜尋過濾的邏輯？
監聽 Input -> 取得 Value -> 迴圈比對文字 -> 符合的 display: block，不符的 display: none。
為什麼外部連結要加 noopener？
安全性考量。防止新開的視窗透過 JS (`window.opener`) 控制原視窗。
Console.log 的用途？
除錯用。就像在 Shell Script 裡 echo $VAR 查看變數狀態。
Phase 4: 網管知識 (Domain Knowledge)
chmod 755 代表什麼？
Owner: rwx (7), Group: rx (5), Others: rx (5)。
RAID 0, 1, 5 簡述？
0: 效能高無備份; 1: 鏡像備份容量半減; 5: 同位檢查碼，容許壞一顆。
HTTP 200 vs 404 vs 500？
200: 成功; 404: 找不到檔案 (Client錯); 500: 程式崩潰 (Server錯)。
DNS A Record 是什麼？
將 Domain Name 對應到 IPv4 Address 的紀錄。
DNS CNAME 是什麼？
別名 (Alias)，將一個 Domain 指向另一個 Domain。
Ping 指令是用什麼協定？
ICMP (Internet Control Message Protocol)。
Traceroute 的作用？
追蹤封包經過的每一個 Hop (Router)，用來判斷網路斷在哪個節點。
img loading="lazy" 是什麼？
延遲載入。瀏覽器只載入捲軸視窗內的圖片，節省頻寬與流量。
YouTube iframe 怎麼做 RWD？
外層容器設 padding-bottom: 56.25% (16:9)，iframe 設絕對定位撐滿。
Localhost 的 IP 是？
127.0.0.1 (Loopback Interface)。
Phase 5: 部署上線 (DevOps)
git init 會產生什麼？
.git 隱藏目錄。它是版本控制的資料庫。
.gitignore 的作用？
Git 的黑名單 (Deny List)。排除系統檔 (.DS_Store) 或敏感資料。
git remote add origin 是做什麼？
設定遠端倉庫地址 (Upstream Server)，讓本地知道要推送到哪裡。
git push -u 是什麼意思？
推送並設定 Upstream，下次只要打 git push 就會預設推到這裡。
GitHub Pages 是什麼？
GitHub 提供的靜態網頁託管服務 (Static Hosting)。
GitHub 現在還支援密碼登入嗎？
不支援。必須使用 Personal Access Token (PAT) 或 SSH Key。
Client-side vs Server-side 差別？
GitHub Pages 是 Client-side (瀏覽器執行 JS)，無法跑 PHP/Python 等後端語言。
綁定 Domain 需要設定什麼 DNS？
CNAME Record。將 www 指向 yourname.github.io。
README.md 是什麼格式？
Markdown。是專案的說明文件 (Man page)。
什麼是 CI/CD？
持續整合/持續部署。例如用 GitHub Actions 自動檢查 HTML 語法並部署。
