硬碟蛋糕切法 I：分區與檔案系統

買了一顆新硬碟插上去就能用嗎？當然不行。你需要經過「分區、格式化、掛載」三個步驟。這就像買回來一塊大蛋糕，你得先切塊，塗上奶油，最後放到盤子上才能吃。

1 儲存管理四部曲

🍰 蛋糕師傅的比喻

  1. 識別 (Identify)：確認買回來的蛋糕（硬碟）叫什麼名字？(e.g., /dev/vdb)
  2. 分區 (Partition)：把蛋糕切成小塊。使用 fdisk (傳統切法) 或 gdisk (新式切法)。
  3. 格式化 (Format)：在切好的蛋糕上抹奶油、打格子，讓它變成可以寫字的狀態 (File System)。常用格式：xfs, ext4。
  4. 掛載 (Mount)：把蛋糕放到桌子的某個盤子 (目錄) 上，這樣大家才拿得到。

2 步驟一：切蛋糕 (fdisk/parted)

首先，用 lsblk 看看你的硬碟在哪。

[root@host ~]# lsblk NAME MAJ:MIN RM SIZE RO TYPE MOUNTPOINT vdb 252:16 0 10G 0 disk # 看到 vdb 了，它是一顆 10G 的硬碟，還沒被切過。

開始切分區：

[root@host ~]# parted /dev/vdb mklabel gpt # 建立分區表 (GPT 是現代標準，MBR 是舊的)。 [root@host ~]# parted /dev/vdb mkpart primary xfs 2048s 1000MB # 切一個 1GB 的分區。 # 或者使用互動式的 'gdisk /dev/vdb' (推薦新手練習 gdisk，介面跟 fdisk 很像)。

💡 udevadm settle

切完分區後，系統核心有時候還沒反應過來。執行 udevadm settle 可以強制系統重新掃描裝置，確保 /dev/vdb1 出現。

3 步驟二：抹奶油 (mkfs)

分區切好了，現在要建立檔案系統 (File System)。Red Hat 預設使用 XFS。

[root@host ~]# mkfs.xfs /dev/vdb1 # 將第一個分區格式化為 XFS。 [root@host ~]# mkfs.ext4 /dev/vdb1 # 如果你想用 ext4 也可以，但 RHEL 推薦 XFS。

4 步驟三：端上桌 (mount)

Linux 的硬碟不是 C: D: 槽，而是掛載在某個「目錄」底下。

[root@host ~]# mkdir /data # 1. 準備盤子 (建立掛載點目錄)。 [root@host ~]# mount /dev/vdb1 /data # 2. 把蛋糕放到盤子上。現在你存進 /data 的東西，實際是存到 vdb1 硬碟裡。 [root@host ~]# df -h # 檢查掛載情形 (Disk Free)。

5 步驟四：永久掛載 (/etc/fstab)

🔥 考試地雷

用 mount 指令掛載只是暫時的！重開機後就會不見。 你必須寫入 /etc/fstab 設定檔，硬碟才會在開機時自動掛載。 寫錯 fstab 會導致無法開機！請務必小心。

使用 UUID (身分證字號) 來掛載最安全，因為裝置名稱 (vdb) 可能會變。

[root@host ~]# blkid /dev/vdb1 /dev/vdb1: UUID="1234-5678-abcd..." TYPE="xfs" # 複製這個 UUID。 [root@host ~]# vim /etc/fstab # 新增一行： UUID=1234-5678... /data xfs defaults 0 0

驗證 fstab (保命招式)：

[root@host ~]# mount -a # 嘗試掛載 fstab 裡的所有東西。如果沒報錯，代表你寫對了。 # 如果報錯，千萬不要重開機，快回去修 fstab！

🧪 今日實戰 Lab：新增資料碟

假設你的虛擬機有一顆閒置硬碟 /dev/vdb (如果沒有，請在虛擬機設定裡加一顆)。

  1. 分區：
    建立一個 500MB 的分區 /dev/vdb1。
    parted /dev/vdb mklabel gpt mkpart primary xfs 2048s 500MB
  2. 格式化：
    格式化為 XFS。
    udevadm settle; mkfs.xfs /dev/vdb1
  3. 永久掛載：
    建立 /newstorage 目錄，並設定開機自動掛載。
    1. mkdir /newstorage
    2. blkid 取得 UUID。
    3. 編輯 /etc/fstab。
    4. mount -a 測試。
