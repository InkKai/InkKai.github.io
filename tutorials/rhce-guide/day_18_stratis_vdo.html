進階儲存技術：Stratis 與 VDO

LVM 很棒，但步驟太繁瑣 (PV->VG->LV->FS)。Stratis 讓儲存管理變得像傻瓜相機一樣簡單。而 VDO 則能幫你省下昂貴的 SSD 空間。

1 Stratis：儲存池管理

🏊 游泳池的比喻

Stratis 就像一個大游泳池 (Pool)。你不用管水管怎麼接 (PV/VG/LV)，只要把水龍頭 (Block Device) 打開，水就會流進池子。你需要多少水 (FileSystem)，直接從池子舀就好，不用預先切格子。

安裝與啟動

[root@host ~]# dnf install stratisd stratis-cli -y [root@host ~]# systemctl enable --now stratisd # Stratis 是透過一個守護進程 (stratisd) 來管理的。

建立 Pool 與 FS

[root@host ~]# stratis pool create mypool /dev/vdb # 建立一個叫 mypool 的池，使用 /dev/vdb 硬碟。 [root@host ~]# stratis filesystem create mypool myfs # 在池子上建立一個叫 myfs 的檔案系統。 # 注意：它會自動格式化成 XFS，你不用自己 mkfs！

2 VDO：虛擬資料最佳化

🗜️ 壓縮袋的比喻

VDO (Virtual Data Optimizer) 做兩件事：
1. 去重複 (Deduplication)：如果你存了 10 次一樣的檔案，它只會存 1 份。
2. 壓縮 (Compression)：像 Zip 一樣把檔案壓小。
結果：1TB 的硬碟可能可以存 3TB 的資料！

RHEL 9 的 VDO 整合進了 LVM：

[root@host ~]# dnf install lvm2 kmod-kvdo vdo -y # 安裝 VDO 相關套件。 [root@host ~]# lvcreate --type vdo -n vdo_lv -L 5G -V 15G myvg # 這行指令很神奇： # -L 5G: 實際佔用硬碟 5G。 # -V 15G: 騙系統說我有 15G (Virtual Size)。 # 這就是 VDO 的魔法：超賣空間。

🧪 今日實戰 Lab：Stratis 實作

假設你有閒置硬碟 /dev/vdc。

  1. 安裝 Stratis：
    安裝套件並啟動服務。
    dnf install stratisd stratis-cli; systemctl enable --now stratisd
  2. 建立儲存池：
    建立 pool1，使用 /dev/vdc。
    stratis pool create pool1 /dev/vdc
  3. 建立檔案系統：
    建立 fs1。
    stratis filesystem create pool1 fs1
  4. 掛載：
    建立 /mnt/stratis 並掛載。
    注意：Stratis 的 UUID 查詢要用 stratis fs list 或 lsblk --output=UUID。
