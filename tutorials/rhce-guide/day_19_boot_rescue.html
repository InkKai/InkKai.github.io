開機流程與救援：忘記密碼怎麼辦？

這是最刺激的一課。當你忘記 Root 密碼，或者系統開不起來時，你需要進入「緊急模式」動手術。這是成為駭客（誤）的第一步。

1 開機四部曲

🌅 起床儀式

  1. BIOS/UEFI：鬧鐘響了，通電，檢查硬體。
  2. Bootloader (Grub2)：決定要穿哪件衣服（選哪個 Kernel）。在這個階段我們可以攔截開機流程！
  3. Kernel：大腦清醒，掛載 / 根目錄 (唯讀)。
  4. Systemd：總管起床，開始叫醒其他服務 (Services)。

2 實戰：重設 Root 密碼

RHCSA 考試第一題通常就是這個：你無法登入 Root，請重設密碼。

操作步驟 (背下來！)

  1. 重開機，在 Grub 選單畫面按 e (Edit)。
  2. 找到 linux 開頭的那一行 (很長)。
  3. 在該行最後面加上 rd.break。
    (這會讓開機停在切換 root 之前)
  4. 按 Ctrl + x 啟動。
  5. 重新掛載硬碟為可寫：
    mount -o remount,rw /sysroot
  6. 切換環境 (Chroot)：
    chroot /sysroot
    現在你是真的 Root 了。
  7. 改密碼：
    passwd root
  8. ★ 關鍵一步：SELinux 重貼標籤
    touch /.autorelabel
    沒做這步，開機後還是進不去！
  9. 輸入兩次 exit 重開機。

3 Systemd Targets (Runlevels)

決定開機後要進入什麼模式。

Target 用途
multi-user.target 多使用者文字模式 (以前的 Runlevel 3)。伺服器預設。
graphical.target 圖形介面模式 (以前的 Runlevel 5)。有 GUI。
emergency.target 緊急模式。只有最基本的唯讀系統，用於修復。
[root@host ~]# systemctl get-default # 查看目前預設開機模式。 [root@host ~]# systemctl set-default multi-user.target # 設定下次開機只進文字模式 (省資源)。
