門禁森嚴：檔案權限與擁有者

Linux 的安全核心就是「權限」。誰能看這個檔案？誰能執行這個程式？今天我們要學會解讀那些神秘的 rwxr-xr-x 代碼，並掌握修改它們的咒語。

1 權限三部曲：r, w, x

🔐 門禁卡的比喻

每個檔案都像一個房間，門上有三個鎖孔：

  • r (Read)：眼睛看。你可以看到房間裡有什麼（讀取檔案內容 / ls 列出目錄）。
  • w (Write)：筆寫。你可以更改房間裡的擺設（修改、刪除檔案 / 在目錄裡建檔）。
  • x (Execute)：進去執行。如果它是程式，你可以執行它；如果它是目錄，你可以 cd 進去。

2 解碼行動：讀懂 ls -l

當你輸入 ls -l，你會看到類似 -rwxr-xr-- 的東西。我們來拆解它：

- rwx r-x r--
檔案類型
( -: 檔案, d: 目錄 )
User (擁有者)
可以讀寫執行
Group (群組)
可以讀和執行
Other (其他人)
只能讀

3 更改權限：chmod (Change Mode)

有兩種改法：數字法（高手用）和 符號法（新手用）。

數字法 (二進位加法)

r=4, w=2, x=1。把它們加起來。

[student@localhost ~]$ chmod 755 script.sh # 7 = 4+2+1 (User: rwx) # 5 = 4+0+1 (Group: r-x) # 5 = 4+0+1 (Other: r-x)

符號法 (直覺)

u=user, g=group, o=other, a=all。 +=加權限, -=減權限。

[student@localhost ~]$ chmod u+x script.sh # 幫擁有者 (u) 加上執行 (x) 權限。

4 更改擁有者：chown (Change Owner)

這個指令通常需要 sudo，因為你不能隨便把東西塞給別人。

[root@localhost ~]# chown tony:devops file.txt # 把 file.txt 送給 tony (User)，並歸類到 devops (Group)。 # 格式：chown User:Group 檔名 [root@localhost ~]# chown -R tony:devops /home/tony/project # -R (Recursive)：連資料夾裡面的東西一起改。

5 特殊權限：SUID, SGID, Sticky

🔥 考試加分題

這三個特殊權限是進階考點。

權限 代碼 功能
SUID u+s 執行時，暫時變身為檔案擁有者。例如 passwd 指令有 SUID，所以一般人執行它時，會暫時變成 root 去改密碼檔。
SGID g+s 用於目錄。在此目錄下建立的新檔案，自動繼承目錄的群組。適合部門共用資料夾。
Sticky Bit o+t 用於目錄（如 /tmp）。只有檔案擁有者才能刪除自己的檔案，別人不能亂刪。

🧪 今日實戰 Lab：機密文件保護

  1. 準備環境：
    建立一個檔案 secret.txt。
    touch secret.txt
  2. 權限設定 (chmod)：
    設定權限：你自己可以讀寫，群組只能讀，其他人什麼都不能做 (640)。
    chmod 640 secret.txt
  3. 擁有者移交 (chown)：
    將這個檔案送給使用者 root (需要 sudo)。
    sudo chown root secret.txt
  4. 驗收：
    試著去讀取這個檔案，應該會看到 Permission denied。
    cat secret.txt
