1. 語義化 HTML 應用 (SEO 基礎)

提問範例 (Prompt)： 請為一個部落格文章頁面設計 HTML 結構。確保使用所有必要的 HTML5 語義標籤，例如 `<header>`、`<nav>`、`<article>`、`<section>` 和 `<footer>`。

// ChatGPT 會輸出的程式碼骨架範例
<main>
    <article>
        <header>
            <h1>文章標題</h1>
            <time datetime="2025-10-27">2025年10月27日</time>
        </header>
        <section>
            <p>文章內容第一段...</p>
        </section>
        <footer>
            <p>作者資訊...</p>
        </footer>
    </article>
</main>

2. CSS Grid 與 Flexbox 佈局 (響應式設計)

提問範例 (Prompt)： 我需要一個響應式的三欄佈局。請給我一個使用 CSS Grid 的範例程式碼，要求主內容佔兩欄，側邊欄佔一欄，並且在手機上使用 Media Query 變成單一堆疊。

/* ChatGPT 會輸出的 CSS 範例 */
.container {
    display: grid;
    grid-template-columns: 2fr 1fr; /* 桌面：2:1 比例 */
    gap: 20px;
}

@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr; /* 手機：單欄堆疊 */
    }
}

3. 表單驗證邏輯生成 (JavaScript 應用)

提問範例 (Prompt)： 請撰寫一段簡單的 JavaScript 函數 `validateEmail(email)`，用來檢查輸入的電子郵件內容是否符合標準的電子郵件格式，並在不符合時回傳 `false`。

// ChatGPT 會輸出的 JS 範例
function validateEmail(email) {
    const re = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return re.test(String(email).toLowerCase());
}

4. 圖片優化與 Lazy Loading (性能)

提問範例 (Prompt)： 我有大量圖片，請提供優化網頁載入速度的 HTML 語法，使圖片能在滾動到視窗時才載入（Lazy Loading），並建議最佳圖片格式。

// ChatGPT 會輸出的 HTML 圖片優化範例
<!-- 關鍵是 loading="lazy" 屬性 -->
<img src="placeholder.jpg" 
     data-src="high_quality.webp" 
     alt="圖片描述" 
     loading="lazy">

5. CSS 動畫與轉換 (視覺效果)

提問範例 (Prompt)： 我需要一個按鈕滑鼠懸停 (Hover) 時，背景顏色在 0.3 秒內平滑地從白色變為藍色，並且向上輕微位移 3 像素的 CSS 程式碼。

/* ChatGPT 會輸出的 CSS 動畫範例 */
.button {
    transition: all 0.3s ease;
}
.button:hover {
    background-color: #3498db;
    transform: translateY(-3px);
    box-shadow: 0 5px 10px rgba(0, 0, 0, 0.2);
}

6. JavaScript 事件處理 (互動)

提問範例 (Prompt)： 請為一個 ID 為 `toggleBtn` 的按鈕，編寫一段 JS 程式碼。要求點擊時，讓 ID 為 `contentBox` 的元素在 CSS 類別 `hidden` 之間切換 (Toggle)。

// ChatGPT 會輸出的 JS 範例
document.getElementById('toggleBtn')
    .addEventListener('click', function() {
        document.getElementById('contentBox')
            .classList.toggle('hidden');
    });
