⚛️ 關於 React

React 的核心思想是什麼？

React 是一個專注於建立使用者介面 (UI) 的 JavaScript 函式庫。它的核心是將複雜的 UI 拆分成獨立、可重複使用的單元，稱為 **元件 (Components)**。

什麼是狀態 (State)？

狀態 (State) 是元件內部的記憶體。當您在計數器中點擊按鈕時，是透過呼叫 `setCount` 更新狀態。React 會自動偵測狀態變化並高效地重新渲染畫面。

什麼是虛擬 DOM (Virtual DOM)？

虛擬 DOM 是 React 用來提高效能的機制。它在記憶體中維護真實 DOM 的副本，只找出需要變動的最小部分，然後才去更新瀏覽器中的真實 DOM，以提高渲染效率。
